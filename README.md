# 🛒 Modern Shopping Cart UI

A clean, responsive shopping cart interface with payment form functionality built with pure HTML, CSS, and JavaScript.

Shopping Cart Screenshot: https://imgur.com/AiCN8Qd
https://imgur.com/Qx5CUIV

## ✨ Features

- **Interactive Cart Items**
  - Quantity adjustment (+/- buttons)
  - Product removal
  - Responsive product cards

- **Payment Form**
  - Credit card type selection with SVG icons
  - Form validation
  - Responsive layout

- **Order Summary**
  - Subtotal calculation
  - Shipping costs
  - Total amount

- **Modern UI Elements**
  - Clean color scheme
  - Smooth hover effects
  - Custom checkbox styling
  - Mobile-responsive design

## 🛠️ Tech Stack

- **Frontend**
  - Semantic HTML5
  - CSS3 (Flexbox, Grid)
  - Vanilla JavaScript
  - SVG icons

- **Design**
  - Roboto Google Font
  - Custom color palette (#4E31AA, #3795BD)
  - Modern card-based layout

## 🚀 Installation

No installation required - this is a pure frontend project.
